# Documents de conformité — BROUILLONS

Ces documents sont des **points de départ rédigés pour l’établissement**, pas des avis juridiques. Ils doivent être relus, complétés et validés par la direction, le délégué à la protection des données (DPO) et, pour l’aspect religieux, la direction juive de l’établissement avant toute utilisation avec de vrais élèves. Les références légales sont citées de mémoire et **à vérifier**.

## Restent à produire par l’établissement
Registre des traitements ; contrats de sous-traitance (hébergeur, fournisseur IA) avec lieux de traitement (UE) et rétention ; politique de conservation et de purge ; procédure de violation de données (72 h) ; plan de reprise (sauvegarde chiffrée hors hébergeur et restauration testée) ; fiche de qualification au regard du règlement européen sur l’IA (rester hors usages à haut risque pendant le pilote : pas de note officielle, pas d’orientation automatisée, pas de détection de triche, pas de reconnaissance d’émotions) ; recueil de l’autorisation parentale selon l’âge.
