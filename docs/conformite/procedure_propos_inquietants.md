# Procédure : propos inquiétants d’un élève (brouillon)

**Déclencheur** : alerte « élève à contacter » du tableau de bord d’administration (le message n’est pas conservé ; on connaît seulement l’élève, la classe, la catégorie et l’heure).

1. **Qui** : une cellule restreinte désignée par la direction [à nommer : direction, CPE, infirmière/psychologue]. L’administrateur qui voit l’alerte la transmet immédiatement à cette cellule.
2. **Quand** : le jour même, en priorité ; en dehors des heures de classe, selon l’organisation de l’établissement [à définir].
3. **Comment** : un adulte rencontre l’élève (sans le sanctionner pour avoir écrit), l’écoute, évalue le danger. Danger immédiat : appeler le **15** ou le **112** ; sinon contacter la famille selon la situation, orienter vers le **3114**. Violences ou harcèlement : suivre le protocole de l’établissement (**3020**, **119**).
4. **Traçabilité** : marquer l’alerte « traitée » ; consigner la suite dans le dossier de vie scolaire, pas dans IABNE.
5. **Rappels** : ne pas rechercher le message de l’élève ; ne jamais le communiquer à d’autres élèves ; l’outil ne détecte pas tout.
6. **Révision** : revoir cette procédure chaque trimestre et enrichir les motifs de détection avec la vie scolaire.
